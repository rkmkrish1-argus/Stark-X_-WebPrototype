# Stark-X — Live Web Prototype & Digital Twin
### Smart Solar-Powered Agarbatti Drying Chamber with Dynamic Louver Control
**SIH 2026 Problem Statement:** PS 26022  
**Parent Repository:** [Stark-X](https://github.com/rkmkrish1-argus/Stark-X)  

---

## 🌟 Overview
Interactive digital twin simulation and web prototype demonstrating:
- **Lumped Thermal Physics Model** for Agarbatti drying kinetics
- **Dynamic Thermal Louver Control** (0° to 30° actuation)
- **PWM Fan Speed Control & Humidity Evacuation**
- **Moisture vs. Time & Temperature Real-Time Plotting**
- **Off-Grid Solar Thermal Retention Simulation**

## 🚀 Live Demo & Usage
Open `index.html` in any modern web browser or host via **GitHub Pages**.
- Adjust solar insolation, ambient temperature, and ambient RH.
- Toggle louver states and fan speeds to observe drying rates and fragrance preservation.
